# سياسة أمن أولية

- استخدم HTTPS في النشر واضبط Secure cookies.
- لا تحفظ الأسرار أو مفاتيح AES داخل Git أو ملفات المصدر.
- لا تعرض الملفات المرفوعة مباشرة؛ افحص النوع والمحتوى ومكافحة البرمجيات الضارة أولاً.
- اجعل مجلد الرفع خارج المسار العام، واستخدم أسماء تخزين عشوائية.
- لا تعتمد على عنوان IP لتحديد الموقع الدقيق؛ الموقع الجغرافي تقريبي ويخضع للخصوصية.
- لا تعتبر سجل التدقيق وحده دليلاً جنائياً غير قابل للتلاعب؛ احمِه بصلاحيات وتخزين منفصل ونسخ احتياطية.
