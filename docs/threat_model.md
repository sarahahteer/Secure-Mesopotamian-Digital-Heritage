# نموذج التهديدات الأولي

## الأصول
- بيانات الباحثين وحساباتهم.
- السجلات الأثرية والوثائق.
- الصور والملفات الأصلية.
- مفاتيح التشفير وسجلات التدقيق.

## التهديدات
- الوصول غير المصرح به وتجاوز الصلاحيات.
- حقن SQL وXSS وCSRF.
- رفع ملفات ضارة أو مزيفة النوع.
- سرقة الجلسات وكلمات المرور.
- العبث بالسجلات أو الملفات.
- تسريب بيانات الاتصال والسجلات.

## الضوابط
- صلاحيات خادمية افتراضية المنع.
- ORM وCSRF وحماية الجلسات وتحديد المعدل.
- عزل الملفات وفحصها قبل إتاحتها.
- تشفير موثّق AES-GCM وحفظ المفاتيح خارج المستودع.
- سجلات تدقيق محدودة الوصول واختبارات أمنية دورية.

هذا مستند ابتدائي ويجب مراجعته وتوسيعه بعد تحديد بيئة النشر والبيانات الحساسة.
